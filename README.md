# 📝 To-Do List Maker

A simple command-line To-Do List application built with Python that allows users to manage their daily tasks efficiently.

## 🚀 Features

* ➕ Add New Tasks
* ❌ Remove Existing Tasks
* ✏️ Update/Edit Tasks
* 📋 View All Tasks
* 💾 Export Tasks to a Text File
* 🛡️ Error Handling for Invalid Inputs
* ⌨️ Keyboard Interrupt Support (`Ctrl + C`)

---

## 📸 Menu Options

```text
1 - Add a New Task
2 - Remove a Task
3 - Change a Task
4 - View All Tasks
5 - Export All Task into File
6 - Exit
```
